# lintblob

Lint config/blob key checks for twelve-factor services.

**Site:** https://theworker02.github.io/lintblob/

## Install / run

```bash
git clone https://github.com/theworker02/lintblob.git
cd lintblob
node src/cli.js
node --test
```
